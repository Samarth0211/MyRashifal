HOW TO CREATE REEL VIDEOS:
==========================

1. Open any reel HTML file in Google Chrome
2. Press F11 for fullscreen (or resize window to 1080x1920 if recording)
3. Use screen recording:
   - Windows: Win + G (Xbox Game Bar) > Record
   - OBS Studio (free): set canvas to 1080x1920, window capture
   - Chrome DevTools: F12 > ... > More tools > Rendering > Emulate viewport 1080x1920
4. Refresh the page (F5) to replay animations from start
5. Record for ~6-8 seconds (animations complete in ~4s)
6. Trim the video if needed
7. Upload directly to Instagram Reels

TIP: For best quality, use Chrome DevTools:
  - Press F12 > Toggle Device Toolbar (Ctrl+Shift+M)
  - Set dimensions to 1080 x 1920
  - Click the 3-dot menu > Capture screenshot or record
